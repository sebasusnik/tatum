# Module parameters

Values are floats in the listed range. `choice` params take an option name
(`waveform half_sine`); a numeric value encodes as index / (options - 1).
FM modules also accept `op<N>_envelope <attack> <decay> <sustain> <release>` as a
shorthand for the four per-operator envelope params.
Generated by `synth params`; do not edit by hand.
