# synth-core

A Rust synthesizer engine (`no_std`, zero dependencies) that plays songs written in a
strict text format, `.synth`. Four Volca-style instruments (acid bass, 4-op FM, poly keys,
drum machine), a 16-step sequencer with swing, ties, slides, arpeggiator and parameter
locks, insert and send effects, scenes and an arrangement. Runs natively, in the browser
through WASM, and as a CLI.

```
cargo run -p synth-cli -- check examples/acid_arp.synth
cargo run -p synth-cli -- render examples/acid_arp.synth -o acid_arp.wav
cargo run -p synth-cli -- params bass
```

- `docs/DSL.md`: the language reference.
- `docs/PARAMS.md`: every module parameter (generated by `synth params`).
- `docs/MCP.md`: the MCP server that lets Claude write songs with the compiler in the loop.
- `ROADMAP.md`: where this is going.
- `examples/`: songs across genres; each one compiles and renders.

Workspace: `core` (engine, DSL, registry), `cli`, `wasm`, `mcp`, `web` (Solid.js livecoding UI).
